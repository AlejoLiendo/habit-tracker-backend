# Habit Tracker - Backend

API REST para el seguimiento de hábitos personales. Permite registrar hábitos con descripción y frecuencia configurable, y calcula automáticamente rachas de cumplimiento.

## Tecnologías

- **NestJS** + TypeScript
- **SQLite** (via TypeORM)

## Funcionalidades

- Crear, editar y eliminar hábitos
- Registrar frecuencia de cumplimiento
- Sistema de rachas automático

## Instalación

```bash
npm install
npm run start:dev
```
